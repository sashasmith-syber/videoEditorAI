## Quick Start

### Desktop Application (Recommended)
```bash
# Build
cd vfiles
v desktop_app.v

# Run
./desktop_app  # or desktop_app.exe on Windows
```

See [DESKTOP_APP.md](DESKTOP_APP.md) for detailed instructions.

### Command Line
```bash
cd vfiles
v run videoeditor.v --help
```
